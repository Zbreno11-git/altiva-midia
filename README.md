# altiva-midia

Mídia **pública** das redes da Altiva (@altiva_serra): só peças prontas para
publicar, enviadas aqui para o Metricool buscar por link na hora de agendar.

- Uma pasta por semana (`AAAA-MM-DD/`), e todo arquivo com a data na frente.
- Nunca entra aqui: rascunho, dado interno, número sem data e fonte, pessoa sem
  autorização. Tudo o que entra fica no histórico do git, mesmo se apagado.
- Imagem em JPEG (a API do Instagram não aceita PNG); vídeo em MP4 H.264.
